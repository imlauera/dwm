# DWM Shortcuts (Mod = Super/Windows)

## Basic Navigation
| Shortcut | Action |
|----------|--------|
| `Mod+Shift+Return` | Open Alacritty |
| `Mod+p` | Open dmenu |
| `Mod+Shift+b` | Open Chromium |
| `Mod+b` | Toggle bar |

## Window Management
| Shortcut | Action |
|----------|--------|
| `Mod+j / k` | Next/previous window |
| `Mod+h / l` | Resize master area |
| `Mod+i / d` | Increase/decrease windows in master |
| `Mod+Return` | Move window to master |
| `Mod+Tab` | Go to previous tag |
| `Mod+Shift+c` | Close window |

## Layouts
| Shortcut | Action |
|----------|--------|
| `Mod+t` | Tile layout (`[]=`) |
| `Mod+f` | Floating layout (`><>`) |
| `Mod+m` | Monocle layout (`[M]`) |
| `Mod+Space` | Cycle layouts |
| `Mod+Shift+Space` | Toggle floating |

## Tags (Workspaces)
| Shortcut | Action |
|----------|--------|
| `Mod+1-9` | Switch to tag 1-9 |
| `Mod+Shift+1-9` | Move window to tag 1-9 |
| `Mod+0` | View all tags |
| `Mod+Shift+0` | Move window to all tags |

## Multi-monitor
| Shortcut | Action |
|----------|--------|
| `Mod+, / .` | Switch monitor (prev/next) |
| `Mod+Shift+, / .` | Move window to monitor |

## System
| Shortcut | Action |
|----------|--------|
| `Mod+Shift+↑/↓` | Volume up/down |
| `Mod+Shift+m` | Mute/unmute |
| `Mod+Shift+l` | Lock screen |
| `Mod+Shift+b` | Brightness +10% |
| `Mod+Shift+v` | Brightness -10% |
| `Mod+Shift+f` | Screenshot (selection) |
| `Mod+Shift+s` | Screenshot (full) |
| `Mod+Shift+q` | Quit dwm |

## Features
- **Theme**: Catppuccin Mocha
- **Font**: JetBrainsMono Nerd Font
- **Gaps**: 10px between windows
- **Statusbar**: Shows date, time, battery, volume, memory, CPU temp
